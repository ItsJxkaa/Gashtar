Local analysis API

Send X-API-Key with every request under /api/v1/.

POST /api/v1/analyze

Multipart upload: field file, MOV/MP4/M4V, up to 150 MB. Response 202:

{"job_id": "..."}

GET /api/v1/jobs/{job_id}

Poll until status is done or failed.

{
  "job_id": "...",
  "status": "done",
  "verdict": "violation",
  "violations": [{
    "type": "Event type",
    "timecode_sec": 12.3,
    "description": "Visible evidence and reason for review",
    "evidence_frames": [{
      "timestamp_sec": 12.3,
      "image_base64": "JPEG bytes encoded as base64"
    }],
    "rule": {"section": "Clause", "url": "Official source"}
  }]
}

A negative result uses no_violation and an empty list. A failed job has an error message and no verdict.

GET /api/v1/rules

Verified rule catalogue and visual limits.

Status codes

401: missing or wrong key. 413: file too large. 415: unsupported extension. 422: missing/empty file. 429: GPU busy; retry later. 503: model or key not configured.
